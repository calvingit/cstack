# cstack-simplify · 简化代码

## 强制约束

- 保持已确认的行为、兼容性和相关工作不变；减少行数本身不是目标。
- 单凭相似代码、短文件或风格偏好，不足以证明可以删除。
- 搜索没结果不能证明没人用；动态调用、外部使用或历史数据核对不了时，先保留并说明。
- 只读或按授权修改，不扩大范围。

## 产物

- **读**：目标与基线、实际调用方、边界、配置、序列化格式、持久数据、测试。
- **写**：简化建议或改动，加上实际检查记录。不是正式产物。
- 需要与其他 Skill 统一产物命名和字段时，调用 `cstack-core` Skill；未安装时以本节作为最小可用版本。

## 目标

本 Skill 在收尾中执行 **Simplifier** 角色：减少当前代码里仍在维护、却已无必要的概念、状态、路径或重复。收尾可以跳过本 Skill。跳过记为未运行，不视为失败，也不能代替 `cstack-verify` 或 `cstack-review`。

## 候选类型

- 已不承担责任的包装或透传
- 重复的状态、重复的保护
- 过期的兼容路径或死代码
- 只为测试方便而加进生产代码的复杂度

## 判断每处候选

说明三点：它现在承担什么责任；删掉或合并后这份责任怎么保住；预期减少哪些维护成本。判断不了就先保留，并说明哪里不清楚。

## 修改与验证

获得授权后，做范围内最小的完整改动；公共行为不能变，用户确认过的兼容要求要满足。运行相称的检查，再查有没有残留引用，并核对实际 diff。

## 报告与停止

报告确认了哪些简化、哪些保留及为什么、实际检查了什么、还有哪些限制。没有安全且有价值的候选，本身就是有效结果；新发现的需求变化、架构改造或无关清理，都不要自行扩大范围。
