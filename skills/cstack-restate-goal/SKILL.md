# 重述用户目标

只在用户明确调用本 Skill 时使用。根据当前请求及相关上下文，用自己的话说明用户想解决的问题、期望结果和已明确的范围或约束。

区分用户明确说过的内容、可说明依据的理解和仍不清楚的事项；不要把猜测写成用户的决定，也不要添加新的需求、计划或验收条件。用户指定的问题范围优先于无关的长期背景。

直接给出简短重述；如果一项关键含义确实无法确定，指出未知。此操作不启动访谈、修改文件或实施工作。
