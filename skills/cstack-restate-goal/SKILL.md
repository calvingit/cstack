# Restate Goal - 重述用户目标

只在用户明确调用本 Skill 时使用。先看当前请求和相关的上下文，再用自己的话说明用户想解决什么问题、期望什么结果，以及已经明确的范围或约束。

要把三类内容分开：用户明确说过的，能说明依据的理解，还有仍然不清楚的事项。猜测不要写成用户的决定，也不要添加新的需求、计划或验收条件。用户指定的问题范围优先于无关的长期背景。

重述要简短，直接给出。如果有一项关键含义确实无法确定，就说明还不确定的是哪一项。此操作不启动访谈，不修改文件，也不实施工作。
