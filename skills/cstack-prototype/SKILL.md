# Prototype - 制作原型

1. 先明确原型要回答什么问题、要观察哪些结果、范围划到哪里，再读相关的项目约束。用户已经定下的选择直接沿用。关键条件缺失时，就把假设说明白。
2. 再选出足以回答问题的形式：可运行的逻辑或界面、隔离的技术试验，或者适用的 Runtime 原生交互展示。用户指定了交付形式就照办，不强制 HTML、特定框架或持久化。
3. 把原型和模拟的部分明确标识出来。只用隔离的数据和已经获准的外部资源。已有的项目文件要保护好：不把原型默认当作生产实现，也不要自行删除用户的工作。
4. 把相关路径实际运行或操作一遍，记录条件、观察结果和还没验证的部分。结论要回到最初的问题上。模拟行为只证明原型里的结果，不能说明生产系统已经实现，也不能说明它已经通过验收。
5. 交付时说明原型怎么用、结论是什么、限制在哪里。至于是继续实现还是保留原型，由用户的请求决定，不强制创建分支、文档或额外状态。
