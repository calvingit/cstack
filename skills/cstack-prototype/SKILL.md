# 制作原型

1. 明确要回答的问题、需要观察的结果和原型范围；读取相关项目约束。用户已有决定直接沿用，缺少关键条件时说明假设。
2. 选择足以回答问题的形式：可运行的逻辑或界面、隔离的技术试验，或适用的 Runtime 原生交互展示。遵守用户指定的交付形式，不强制 HTML、特定框架或持久化。
3. 明确标识原型和模拟部分，使用隔离数据及获准的外部资源；保护已有项目文件，不把原型默认当作生产实现，也不自行删除用户工作。
4. 实际运行或操作相关路径，记录条件、观察和未验证部分。对照最初的问题给出结论；模拟行为只证明原型中的结果，不证明生产系统已实现或通过验收。
5. 交付原型的使用方式、结论和限制；是否继续实现或保留原型遵循用户请求，不强制创建分支、文档或额外状态。
