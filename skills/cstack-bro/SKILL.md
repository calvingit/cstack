# Bro - 用人话重说

只在用户明确调用本 Skill 时使用。默认重述上一条助手答复。用户指定了片段，就以该片段为范围。找不到原文时，说明缺的是哪一部分，不要猜原答案。

重述时用自然、简洁的说法，让读者容易看懂。原文的关键结论、条件、事实依据、限制，还有不确定到什么程度，都要保留。推测不要写成确定的事实，会改变判断的前提也不要省掉。必要的术语、数字、命令或引用要保留下来，并解释清楚。

不重新调研，也不增加原文没有的观点或行动建议。如果用简短例子能帮助理解，就说清它只是举例说明，不能当作新证据。直接给改写结果。
