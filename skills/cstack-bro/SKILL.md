# Bro - 用人话重说

只在用户明确调用本 Skill 时使用。默认重述上一条助手答复；如果用户指定了片段，以该片段为范围。找不到原文时说明缺口，不猜测原答案。

用自然、简洁的语言重述，让读者容易理解。保留原文的关键结论、条件、事实依据、限制和不确定程度；不要把推测改成确定事实，也不要省掉会改变判断的前提。必要的术语、数字、命令或引用应保留并解释。

不重新调研、不增加原文没有的观点或行动建议。如果一个简短例子有助理解，明确它是说明性的例子，不能当成新证据。直接给改写结果。
