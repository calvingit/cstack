# cstack-restate-goal · 重述用户目标

## 目标

用自己的话简短说明用户想解决什么问题、期望什么结果，以及已经明确的范围或约束。

## 依据

先读当前请求和会话中已确认的内容；存在 DECISIONS 或 PROFILE 时，以其中已确认的内容为准，未确认的内容单独列出。

## 输出结构

把三类内容分开，分别写成三行：

- 用户明确说过的：
- 有依据的推断：
- 仍不清楚的：

## 边界

- 推断不要写成用户的决定，也不要添加新的需求、计划或验收条件。
- 用户指定的问题范围优先于无关的长期背景。
- 如果某个关键点确实无法确定，就指出是哪一点。
- 本 Skill 不启动访谈，不修改文件，也不开始执行任务。
- 交接场景用 `cstack-handoff`；没听懂、需要换个说法重讲时用 `cstack-bro`。
