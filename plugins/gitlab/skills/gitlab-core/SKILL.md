# gitlab-core · 共享知识索引

## 定位

本 Skill **只做索引**：提供 `glab` 命令的已知陷阱、自部署实例的能力矩阵和写操作安全约束。不执行任务、不发评论、不改仓库状态。其他 Skill 通过读取本目录文件使用它，读取本身不扩大任何授权。

| [SAFETY.md](references/SAFETY.md) | 要发评论、批准、推送、建 MR 或改状态之前 | 读写分界、对外动作确认、可回滚性、误操作恢复 |

## 三条最易出错的规则

1. **评论正文里有反引号或 `$`，先写文件再 `$(cat)`。** 直接内联会被 shell 当命令执行，正文被静默截断。
2. **`glab api` 传字段值用 `-f`，不要用 `-F`。** `-F` 会做类型推断，把看起来像数字或文件路径的值送错类型。
3. **退出码 0 不代表写入符合预期。** 写操作后回读实际内容再报告。

## 与实例相关的判断

本索引的经验来自 GitLab CE 16.11。换实例或升级后，先按 [SERVER-MATRIX.md](references/SERVER-MATRIX.md) 的探测步骤确认，不要直接套用旧结论。
